# Yishan Wang's website

Static GitHub Pages site at https://yishani.github.io/. Open `index.html` locally to preview the content; GitHub Pages serves the files directly.

## Page map

- `index.html` — introduction, current research themes, archive, and social links.
- `ai4s.html` — agentic harnesses for AI for science; SimAuthor is a project within this theme.
- `audio-skills.html` — ongoing transferable audio skills research; public overview only, with no unpublished methods or results.
- `healthcare.html` — health signals and hospital collaboration; links to StethoLM and SimAuthor.
- `language-and-people.html` — archive theme containing the negation bias and empathy papers.
- `tags.html` — cross-topic keyword index.
- `pragmatic-intelligence.html` — ongoing research on common ground, repair, and transferable interaction protocols.
- `about.html` — academic background and education; last item in the shared navigation.
- `connect.html` — ways to connect as a researcher, healthcare professional, recruiter, or founder.

Shared visual styles live in `stylesheet.css`. `theme.js` controls the light/dark switch and remembers the visitor's preference. The site uses Manrope from Google Fonts, with the system sans-serif stack as fallback.

To add a paper, put it on the most relevant theme page. Add a cross-link from another theme when useful, and update `tags.html` if the paper introduces a new keyword. Keep the homepage focused on research questions rather than a full publication list.
